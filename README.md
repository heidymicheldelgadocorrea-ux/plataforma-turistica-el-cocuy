# Turismo Inteligente El Cocuy

Prototipo de plataforma web turística inteligente para facilitar el acceso organizado a información turística validada del municipio de El Cocuy.

## Objetivo

Desarrollar un prototipo funcional de una plataforma web inteligente que facilite el acceso organizado, claro y oportuno a información turística de El Cocuy, apoyando a los visitantes en la consulta de atractivos, actividades y servicios turísticos.

## Funcionalidades

La plataforma permite:

- Consultar información sobre atractivos turísticos.
- Consultar los senderos Lagunillas - Púlpito, Laguna Grande de la Sierra y Ritacuba.
- Consultar actividades turísticas.
- Consultar categorías de servicios turísticos.
- Identificar fuentes de referencia de la información.
- Navegar entre diferentes secciones de la plataforma.
- Utilizar la plataforma desde diferentes tamaños de pantalla.
- Interactuar con un chatbot turístico.
- Gestionar consultas cuya información no se encuentre disponible en la base de conocimiento.
- Registrar temporalmente las interacciones realizadas con el chatbot durante la sesión.

## Chatbot turístico

El prototipo incorpora un asistente turístico basado en una base de conocimiento controlada mediante reglas y palabras clave.

El chatbot puede responder consultas relacionadas con:

- Senderos.
- Actividades.
- Alojamiento.
- Alimentación.
- Transporte.
- Atractivos.
- Fuentes de información.

Cuando una consulta no corresponde con la información disponible, el chatbot informa que no dispone de información validada y recomienda consultar fuentes oficiales.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub

## Estructura del proyecto

- `index.html`: estructura y contenidos de la plataforma.
- `estilos.css`: diseño visual y adaptación a diferentes tamaños de pantalla.
- `chatbot.js`: base de conocimiento, lógica del chatbot, medición de tiempos y registro temporal de interacciones.

## Pruebas realizadas

Durante la validación del prototipo se realizaron:

- 10 pruebas funcionales.
- 20 consultas controladas al chatbot.
- Pruebas de consultas sin información validada.
- Medición del tiempo de procesamiento local del chatbot.
- Prueba de adaptación a resolución móvil.
- Prueba piloto de usabilidad con 8 usuarios potenciales.

En la batería funcional se aprobaron 10 de 10 casos.

En la batería controlada del chatbot, 20 de 20 consultas presentaron el comportamiento esperado.

La prueba piloto de usabilidad presentó un promedio general de 4,78 sobre 5.

## Nivel de madurez tecnológica

El prototipo fue desarrollado y validado dentro de un entorno académico simulado con el propósito de sustentar un nivel de madurez tecnológica TRL5.

El sistema todavía no corresponde a una solución productiva desplegada. La base de conocimiento se encuentra incorporada en el prototipo y el registro de las interacciones es temporal durante la sesión del navegador.
